# GearWin — FAQ / Συχνές ερωτήσεις

**Focus / Αντικείμενο:** PC maintenance and recovery / Συντήρηση και ανάκτηση

## Where do I download it? / Πού το κατεβάζω;

[Latest stable published release](https://github.com/gs-applabs/GearWin/releases/latest). Select the official installer and matching SHA-256 file if provided. Read the requirements, limitations and upgrade notes. A hash is an integrity check, not a signature or proof of safety. Do not bypass OS warnings.

## How do I get started? / Πώς ξεκινάω;

Open **System & Tools → Tools** (Σύστημα & Εργαλεία → Εργαλεία). Directly below System Image Backup are the folder-transfer preflight and application-list export. Preflight checks selected folders; it does not copy files. Export is an inventory for planning, not automatic installation on another operating system. See [backup and recovery](disk-backup-and-recovery.md) and [migration CLI](../migration/README.md). Offline clone kit requires a separately booted Linux Live environment; an installer test is not a full restore or boot test.

## What are the limitations? / Ποιοι είναι οι περιορισμοί;

Before system repair, backup or cloning, read the operation-specific warnings and verify your recovery path. / Πριν από επισκευή, backup ή κλωνοποίηση διάβασε τις προειδοποιήσεις και έλεγξε τη δυνατότητα ανάκτησης.

## Where do I find screenshots? / Πού βρίσκω εικόνες;

[Actual Windows CI screenshot gallery](product-snapshots/README.md). Some views use demonstration data. Visual tests are not full functional acceptance tests.

## Can I report a bug or suggest a feature? / Μπορώ να αναφέρω σφάλμα ή να προτείνω δυνατότητα;

[Open an issue](https://github.com/gs-applabs/GearWin/issues/new/choose). Include your app and Windows versions and steps to reproduce. Redact personal data, credentials and confidential files.

## What is planned? / Τι σχεδιάζεται;

Physical hardware recovery and migration acceptance testing; clearer guidance for risky operations.

This is a non-binding direction, not a promised release date. / Ενδεικτική κατεύθυνση, χωρίς δεσμευτική ημερομηνία.
